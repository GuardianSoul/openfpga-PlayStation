PlayStation SD card helper

Optional. Generates one game file per multi-disc game, so you can swap discs in Core Settings → Swap Discs, and gives all of a game's discs one shared memory card. Single-disc games need nothing from this page.

This browser can't write to an SD card.

Open this page in Chrome or Edge on a computer (Windows, macOS, Linux or ChromeOS). Phones, Firefox and Safari don't support it. You can also use make_pocket_instances.py from the README instead.

1Choose your SD card

Put the Pocket's SD card in your computer and pick the card itself (the folder that holds Assets and Cores). Your browser asks once to allow changes to it. Nothing is uploaded; everything runs on your computer.

2Generate the game files

Core:

What it changes on the card

  • Generates one game file per game in Assets/playstation/<core>/. A game with several discs ("Game (Disc 1)", "Game (Disc 2)", …) gets one file, named after the game.
  • Deletes the separate per-disc game files of those games, because the new file replaces them.
  • Gives each multi-disc game one memory card for all its discs, Saves/playstation/common/<game>.sav. It starts as a copy of the card from the disc you played last. If that card already exists, it is left alone. Your other saves are not touched.
  • The game file names the disc's .cue, and the core finds the tracks, the other discs and a LibCrypt .sbi next to it by itself. Nothing else is written.
  • This core is older than 0.5.3, so with the box ticked it splits games that keep all their tracks in one .bin into a folder next to the game. With "Replace the originals" it then deletes the original .bin and .cue, but only after checking the copy.
  • Before writing a large file the page makes sure the card has room for it plus 256 MB to spare. If not, it skips that game and leaves the original as it was.
  • Shows which games it skipped and why. CHD images have to be converted on a computer first, with make_pocket_instances.py or the Pocket Sync / pupdate plugin (see the README).

Generate game files again after adding games. Running pupdate or Pocket Sync afterwards can bring back the one-file-per-disc game files; they still work, but disc swapping needs the combined file.
