PlayStation SD card helper

Optional. Single-disc games already work with the game files that pupdate or Pocket Sync make. This page adds what those tools can't do yet: one game file per multi-disc game, so you can swap discs in Core Settings → Disc, and one memory card that all of a game's discs share.

This browser can't write to an SD card.

Open this page in Chrome or Edge on a computer (Windows, macOS, Linux or ChromeOS). Phones, Firefox and Safari don't support it. You can also use make_pocket_instances.py from the README instead.

1Choose your SD card

Put the Pocket's SD card in your computer and pick the card itself (the folder that holds Assets and Cores). Your browser asks once to allow changes to it. Nothing is uploaded; everything runs on your computer.

2Make the game files

Core:

What it changes on the card

  • Makes one game file per game in Assets/playstation/<core>/. A game with several discs ("Game (Disc 1)", "Game (Disc 2)", …) gets one file, named after the game.
  • Deletes the separate per-disc game files of those games, because the new file replaces them.
  • Gives each multi-disc game one memory card for all its discs, Saves/playstation/common/<game>.sav. It starts as a copy of the card from the disc you played last. If that card already exists, it is left alone. Your other saves are not touched.
  • With the box ticked: splits games that keep all their tracks in one .bin into a folder next to the game, then deletes the original .bin and .cue.
  • Shows which games it skipped and why. CHD images have to be converted on a computer first (see the README).

Run it again after adding games. Running pupdate or Pocket Sync afterwards can bring back the one-file-per-disc game files; they still work, but disc swapping needs the combined file.

Part of the PlayStation core for Analogue Pocket. Source and README: GuardianSoul/openfpga-PlayStation.
