# Compatibility

See the **[game list](https://guardiansoul.github.io/openfpga-PlayStation/compatibility.html)**
and vote how your games run there; no account needed. For a specific
problem, use **Report a problem** on the game or the
[problem form](../../issues/new?template=compatibility.yml).

| Status | Meaning |
| --- | --- |
| Playable | Played into normal gameplay with no problems seen |
| Minor issues | Playable with small graphics or sound glitches |
| Major issues | Starts, but crashes, hangs or is too broken to play |
| Boots | Reaches the title or the first scenes; not played further |
| Doesn't boot | Black screen or hang before the title |
